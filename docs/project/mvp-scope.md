# MVP Scope

Границы первого этапа. Источник: MASTER_PRD.md, архитектурный план.

---

## В scope

- Каталог с типами товаров STANDARD, CONFIGURABLE, BESPOKE и правильными CTA по product rules.
- Корзина и checkout только для товаров, допускающих корзину; оформление заказа без приёма оплаты на сайте.
- Room Sets как отдельная сущность и раздел сайта (/rooms); CTA «Купить комплект», «Адаптировать под мою комнату».
- Формы заявок (bespoke, адаптация комнаты) → создание Lead и BespokeRequest.
- Админка на базе Medusa Admin + расширения: Products, Categories, Orders, Room Sets, Leads, Bespoke Requests, Payment Links.
- **Payment Link в ручном режиме:** админ создаёт ссылку, указывает сумму, отправляет клиенту (email/мессенджер). Статус оплаты при необходимости меняется вручную. Webhook и автоматическое обновление статусов в первом этапе не обязательны.
- Один регион (РФ), одна валюта (RUB).
- Карточка товара: размеры, материалы, срок изготовления, доставка, возможность кастома (по product_type).

---

## Вне scope (не делать в первом этапе)

- Отдельное приложение админки (apps/admin). Только Medusa Admin + расширения внутри backend.
- Личный кабинет.
- Конфигуратор мебели (сложный визуальный конфигуратор).
- Сравнение товаров.
- Интеграции с CRM.
- Meilisearch (поиск — базовый через API Medusa).
- GraphQL, BFF, микросервисы.
- Автоматическое обновление статуса оплаты по webhook (можно добавить позже).
