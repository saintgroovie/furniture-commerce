# Продвижение миграций Стола

Миграции `Migration20260930180000`, `Migration20260930223000` и `Migration20260930224500` по-прежнему отказываются работать вне базы `workspace_it`.

Команда `yarn db:migrate:workspace-production` в `apps/backend` только проверяет условия и завершается с ошибкой. Она не применяет миграции.

Нужны сразу: окружение, ожидаемое имя базы, роль процесса, governance token и SHA миграции. Даже если всё совпало, живой запуск в этой фазе выключен.

`down()` этих миграций удаляет таблицы. Это не безопасный откат данных. Если применение когда-нибудь пойдёт не так, восстановление - копия базы и следующий прямой фикс.
