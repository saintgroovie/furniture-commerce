# Техническая админка Medusa

Обычный сотрудник работает в Столе. Нативный `/app` открывается только почтам из `WOODRIGHT_MEDUSA_ADMIN_EMAILS`.

Гейт включён, если `WOODRIGHT_MEDUSA_ADMIN_UI_GATE=1` или база изолированная (`WOODRIGHT_DB_ISOLATION=isolated`). Пустой список почт никого не пускает. Это не пароль и не скрытая ссылка.

Вызовы `/admin` без заголовка `Origin` остаются для сервера Стола.

## Временно открыть доступ

1. В окружении процесса backend дописать почту в `WOODRIGHT_MEDUSA_ADMIN_EMAILS`.
2. Перезапустить только этот backend.
3. Открыть `/app`, войти этой почтой, убедиться, что интерфейс Medusa открылся.
4. Убрать почту из списка и перезапустить backend ещё раз.
5. Тем же браузером открыть `/app` и убедиться, что доступ закрыт.

На daily и production этот флаг не включать без отдельного решения владельца.
