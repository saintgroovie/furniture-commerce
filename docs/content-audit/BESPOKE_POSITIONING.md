## 1. What Bespoke is

**Woodright Bespoke - новое имя и полноценное premium-переосмысление существующего направления «По проекту».**

Это не новая бизнес-сущность рядом со старой услугой. Базовая услуга та же: клиенту нужно решение, которого нет как обычный товар каталога; Woodright обсуждает задачу, рассчитывает и проектирует, затем производит под проект.

Меняются название, позиционирование, качество подачи, UX, драматургия, структура страницы, journey и объяснение возможностей. Не меняется сама сущность.

Это **не** механическая замена пункта навигации: старую услугу нужно заново качественно представить. Нельзя утверждать, что Bespoke и «По проекту» - разные направления.

Buyer не обязан знать историю переименования. На сайте он видит цельное предложение **Woodright Bespoke**.

### Practical boundary (internal labels)

| Classification | Meaning | Commerce |
| --- | --- | --- |
| `STANDARD` | Готовый товар: существующая модель в предусмотренном исполнении | Обычный каталог / PDP / корзина |
| `CONFIGURABLE` | Тот же существующий товар с **заранее предусмотренными** вариантами (обивка, цвет, отделка, материал, штатный размер, штатная конфигурация) | Обычный товарный сценарий; корзина после выбора. Не «почти Bespoke» |
| `BESPOKE` | Задача **за пределами** предусмотренных вариантов существующего товара. Исторически: «По проекту» | Никогда корзина. Обращение → обсуждение → расчёт / согласование → оформление менеджером (`OD-05`) |

Ключ: **если вариант уже предусмотрен в каталоге - CONFIGURABLE. Если нужно отдельно проектировать, рассчитывать или согласовывать - BESPOKE.**

Эти labels - UX/product journey. **`BESPOKE LABEL != AUTOMATIC NO-RETURN RULE`.** **`CONFIGURABLE LABEL != AUTOMATIC INDIVIDUALLY-DEFINED PROPERTY`.** **`PRODUCT LABEL != AUTOMATIC WARRANTY TERM`.** **`BESPOKE LABEL != AUTOMATIC WARRANTY TERM`.** Returns launch model: `OD-03 = B` (`docs/content-audit/OD03_RETURNS_VERIFICATION.md`). Warranty: `OD-04 = B` (`docs/content-audit/OD04_WARRANTY_VERIFICATION.md`) - base commercial term **12 months** for STANDARD / CONFIGURABLE / BESPOKE; label does not change the term; do not invent «нет гарантии» from the rename. Contract-specific Bespoke exceptions must be separate. Mapping stays `LEGAL REVIEW`. One business entity with «По проекту» → not two return or warranty policies.

Изменение размера **само по себе не определяет** категорию:

- кровать 160 / 180 / 200 см среди штатных вариантов → CONFIGURABLE;
- ширина 187 см, которой нет среди штатных → потенциально BESPOKE;
- кресло: выбор тканей из линейки → CONFIGURABLE; изменить конструкцию → BESPOKE;
- комод: две предусмотренные отделки → CONFIGURABLE; переработать под нишу → BESPOKE;
- свой чертёж / задача / мебель под пространство, которой нет в каталоге → BESPOKE.

Эти три слова - **внутренняя** логика. Покупателя не обучаем taxonomy. Buyer-facing:

**Есть подходящая модель в каталоге → выбираем её.**
**Есть предусмотренные варианты этой модели → настраиваем их.**
**Нужного решения нет → обращаемся в Woodright Bespoke.**

Current live copy is weaker than the proof: it reads as «подберём состав комнаты» / «под ключ», not as production + design for work beyond preset options. That copy gap remains for a later storefront pass.
