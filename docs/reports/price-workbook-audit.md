## Sheet-by-Sheet Notes

### ОЛИВЕР - ЧЕРНЫЙ

- **Заголовок:** Row 2 — название коллекции, Row 5-6 — header
- **Артикул:** Column C (числовой код, напр. `55-2`, `84-2`)
- **Наименование:** Column D
- **КОЛ-ВО:** Column E (всегда 0 — это заказная форма, не stock)
- **ЦЕНА МАССИВ:** Column F — базовая цена в массиве
- **Наценка 15% (ЧЕРНЫЙ BI):** Column G — цена черного варианта = массив × 1.15
- **ЦЕНА ЛДСП:** Column H — цена в ЛДСП (не у всех товаров, у некоторых 0)
- **Габариты:** Column I (merged I-K) — формат `В.XXX х Ш.XXX х Гл.XXX`
- **СУММА:** Columns L-N — расчётные (КОЛ-ВО × ЦЕНА), для storefront не нужны
- **Особенности:** Некоторые товары имеют ЛДСП-вариант, некоторые нет. Артикулы без коллекционного префикса.

### ГРИНВИЧ

- **Артикул:** Column B с префиксом `GR-` (напр. `GR-09-1`)
- **Наименование:** Column C
- **ЦЕНА МАССИВ:** Column E
- **ЦЕНА ЛДСП:** Column F (у большинства 0 — нет ЛДСП-варианта)
- **Габариты:** Column G (merged G-I)
- **Особенности:** Компактная коллекция (16 предметов), преимущественно массив

### ВВ (Willie Winkie)

- **Структура цен — 4 tier-а:**
  - Column F: Tier 1 — Инфанта, Молли/Томми, Королевские лилии, Мишка, Ёжики, Милый Дом
  - Column G: Tier 2 — Муравьишки, Бригантина, Феечки, Королевство фантазий, Королевские гвардейцы, Алиса, Ретро Авто
  - Column H: Tier 3 — Альбион, Балет, Пастораль, Сельский пейзаж, Тамплиеры
  - Column I: Tier 4 — ЛДСП (категория 1)
- **Артикул:** Column C (числовой код без префикса)
- **Наименование:** Column D
- **Габариты:** Column J (merged J-L)
- **Особенности:** Самая сложная ценовая модель. Каждая роспись имеет двухбуквенный код (IN, AV, AL, MO, BRB, RL, TB, TW, SH, FA, FK, RG, SC, RA, BA, PA, RS, TE). Цена зависит от сложности росписи.

### ОКСФОРД

- **Артикул:** Column B с префиксом `OX-` или `MC-` (Мой замок)
- **Наименование:** Column C
- **ЦЕНА:** Column E — единая цена
- **Габариты:** Column F (merged F-H)
- **Особенности:** Модульные комплексы (кровать-чердак, замок). Включает варианты с/без нижней кровати, с/без столешницы. Также содержит предметы «Мой замок» (префикс MC-).

### ПРОВАНС

- **Артикул:** Column C (числовой код без префикса)
- **Наименование:** Column D
- **Два тона:**
  - Column F: ПБ (Прованс белый)
  - Column G: ПТ (Прованс тёмный)
- **Габариты:** Column H (merged H-J)
- **Особенности:** Два цветовых варианта с разными ценами. Форматирование размеров неконсистентное.

### ПРИНЦЕССА РОЗА

- **Артикул:** Column B с префиксом `PR-`
- **Наименование:** Column C
- **ЦЕНА:** Column E — единая цена
- **Габариты:** Column F (merged F-H)
- **Особенности:** Единая цена за все варианты. Некоторые позиции имеют варианты «с рисунком» / «без рисунка» / «с тканью».

### КАНТРИ-ЛОНДОН-ПАРИЖ

- **Три под-коллекции в одном листе:**
  - Column F: КО (Кантри)
  - Column G: ЛО (Лондон)
  - Column H: ПАР (Париж)
- **Артикул:** Column C с префиксом `CO-`
- **Наименование:** Column D
- **Габариты:** Column I (merged I-K)
- **Особенности:** Лондон и Париж часто имеют одинаковую цену, отличающуюся от Кантри. Некоторые позиции есть не во всех трёх под-коллекциях (цена 0).

### МОНЧЕЛСИ

- **Артикул:** Column B с префиксом `MNm-` или `MN-`
- **Наименование:** Column D
- **ЦЕНА МАССИВ:** Column F
- **ЦЕНА ЛДСП:** Column G (у многих товаров 0 — нет ЛДСП-варианта)
- **Габариты:** Column H (merged H-J)
- **Тоновые варианты:** Rows 4-8 описывают 5 тонов (a-d + LD), но цена тона задаётся наценкой (+10% для тёмного дуба), а не отдельной колонкой
- **Особенности:** Крупная коллекция, вторая по размеру. Некоторые строки внизу без артикула.

### Аксессуары

- **Простая структура:** Код, Наименование, Кол-во, Цена, Габариты
- **8 позиций:** валики, подушки, шкатулки, сундук
- **Примечание:** R14 — «Стоимость аксессуаров указана в стандартной ткани 1-2 категории»

### Детали

- **68 позиций** запчастей и фурнитуры
- **Префиксы кодов привязаны к коллекциям:**
  - CO- (2), LO- (2), MN- (10), OL- (9), OX- (1), PA- (4), PR- (3), WW- (34), D- (1), F- (1), R- (1)
- **Содержит:** полки для шкафов, штанги, ручки, замки, филенки, дверцы
- **Некоторые позиции без цены** (ручки PR-h1, PR-h2, PR-h3; ручки WW-h*)
- **Не для карточки товара** — это дополнительные элементы для конфигурирования

### Спецзаказ

- **34 позиции** модификаций и уникальных товаров
- **Два типа цен:**
  - **Multiplier** (коэффициент): `1.05`, `1.1`, `1.15`, `0.95`, `0.7` и т.д. — применяется к базовой цене товара
  - **Absolute** (фиксированная цена): `157000`, `163150` и т.д. — конкретная стоимость
- **Сроки:** Почти все — «45 рабочих дней»
- **Префиксы:** S-MN (Мончелси), S-OL (Оливер), S-WW (ВВ), S-BT (Бертранд), общие (S-01..S-08)
- **Бизнес-смысл:** Это модификации к базовым товарам (перекрас, увеличение размера, замена материала) — соответствует CONFIGURABLE product_type

## Candidate Source-of-Truth Fields

| Поле | Колонка (типичная) | Покрытие | Качество |
|------|-------------------|----------|----------|
| **Артикул / SKU** | B или C | ~95% строк | Хорошее, но форматы разные (с/без префикса) |
| **Наименование** | C или D | ~100% | Хорошее, по-русски |
| **Цена (базовая)** | E, F, или зависит от листа | ~95% | Хорошее, но множественные price columns |
| **Габариты** | Различные (merged cells) | ~90% | Формат неконсистентный |
| **КОЛ-ВО** | Различные | ~100% | Всегда 0 — это заказная форма |
| **Материал/тон** | Заголовки колонок | implicit | Нужно извлечь из header structure |
| **Коллекция** | Имя листа | 100% | Source of truth |

## Ambiguities and Data Cleaning Risks

### 1. Неконсистентный формат артикулов
- Некоторые листы используют префикс коллекции (`GR-09-1`, `PR-55-2`, `MNm-55-1`)
- Некоторые — только числовой код (`55-2`, `84-2`)
- Для Оливера: числовой код, но тон задаётся суффиксом из header
- **Решение:** Нормализовать артикул = `{collection_prefix}-{numeric_code}`

### 2. Множественные ценовые колонки
- Оливер: 3 цены (массив / черный / ЛДСП)
- ВВ: 4 tier-а + ЛДСП
- Прованс: 2 тона
- Кантри-Лондон-Париж: 3 под-коллекции
- **Решение:** Каждая ценовая колонка = отдельный variant (material + finish combination)

### 3. Неконсистентный формат габаритов
- Стандарт: `В.XXX х Ш.XXX х Гл.XXX` (мм)
- Вариации: `500*395*440`, `В1529_Ш1862_Гл2146`, `В.300 х Ш.1000 х Гл. 40`, `900*1850*H200`
- **Решение:** Парсить regex-ом, нормализовать в `{height}×{width}×{depth}` мм

### 4. ЛДСП-вариант есть не у всех товаров
- Когда ЛДСП-цена = 0, это означает «ЛДСП-вариант недоступен»
- **Решение:** Не создавать variant, если цена = 0

### 5. Спецзаказ — multiplier vs absolute
- Multiplier-строки не имеют самостоятельной цены — они модифицируют цену базового товара
- **Решение:** Не создавать отдельные product cards для multiplier-строк. Это bespoke/configurable modifications.

### 6. Merged cells
- Все листы интенсивно используют merged cells для заголовков и габаритов
- openpyxl корректно читает верхнюю-левую ячейку merged range
- **Решение:** При парсинге проверять merged_cells.ranges

### 7. Пустые строки и заметки
- Некоторые строки в конце листов содержат примечания (не товары)
- Строки КОЛ-ВО всегда 0 — это blanket order form, не stock data
- **Решение:** Фильтровать по наличию артикула + наименования + ненулевой цены

## What Should Be Normalized Before Storefront Usage

1. **Артикулы:** Унифицировать формат `{COLLECTION}-{CODE}` для всех товаров
2. **Цены:** Извлечь каждый price point как отдельный variant с атрибутами `{material}` и `{finish/tone}`
3. **Габариты:** Парсить в структуру `{height_mm, width_mm, depth_mm}`
4. **Коллекция:** Имя листа → каноническое название коллекции
5. **Тип товара:**
   - Основные коллекции → STANDARD или CONFIGURABLE (если несколько material variants)
   - Аксессуары → STANDARD
   - Спецзаказ (multiplier) → CONFIGURABLE modification (не отдельный product)
   - Спецзаказ (absolute) → CONFIGURABLE или BESPOKE (зависит от контекста)
6. **Категория:** Определить по наименованию (Кровать, Шкаф, Стол, Комод и т.д.)
