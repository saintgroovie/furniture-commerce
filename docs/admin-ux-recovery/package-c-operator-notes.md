# Package C — operator notes

## Как найти вариант

Откройте товар → **Рабочее пространство Woodright** → вкладка **Варианты и цены**.
Используйте поиск по артикулу (SKU), названию или значению опции (например «Дуб»).

Если у товара один обычный вариант без настоящей матрицы опций, он показан как **Основной вариант**.

## Как понять, что цены нет

В колонке цены будет «—», статус **Нет цены**, в полноте данных — «Требует внимания».
Это не то же самое, что цена **0** (ноль — валидная цена).

## Как изменить SKU

1. Нажмите **SKU** у строки.
2. Измените значение.
3. **Сохранить** или **Отмена**.
Пустой SKU допускается, если система его принимает. Дубликат внутри товара будет отмечен ошибкой.

## Как изменить цену

1. Нажмите **Цена**.
2. Введите целое число в рублях без копеек (пример: `12500` → 12 500 ₽).
3. Сохраните.
Если валют несколько — сначала выберите валюту.
Сложные цены (правила, пороги количества) **не редактируются здесь** — откройте стандартную админку.

## Несколько валют

Цены разных валют показываются отдельно и никогда не складываются в одну сумму.

## Массовое изменение

1. Отметьте нужные строки галочками.
2. **Массовая цена**.
3. Прочитайте preview: сколько изменится, какой диапазон был/станет, кого пропустят и почему.
4. Примените или отмените.
Если часть строк не сохранилась — в отчёте будет список неудач.

## Отмена и ошибки

**Отмена** в строке сбрасывает черновик.
Если уйти со страницы с несохранёнными правками — браузер спросит подтверждение.
При ошибке сохранения текст в поле не очищается: исправьте и повторите.

## Fallback

Ссылка **Открыть варианты в стандартной админке** — для сложных цен, опций, удаления и всего, что Package C намеренно не трогает.
