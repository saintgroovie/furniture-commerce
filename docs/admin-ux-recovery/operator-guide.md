# Руководство оператора - Woodright Admin

Справочник по операторским экранам Woodright. Названия кнопок и вкладок в тексте совпадают с интерфейсом.

Woodright включается флагом `WOODRIGHT_ADMIN_UX_V1` (env и/или localStorage). Если флаг выключен, прямые ссылки на Woodright **сразу открывают** соответствующий экран стандартной админки (без страницы-заглушки). В левом меню остаётся один пункт Woodright: **«Рабочий стол Woodright»**.

Стратегия: **одна админка**. Списки товаров, заказов и акций — в разделах слева. Woodright — очередь задач и мастера (довести карточку, простая акция).

---

## С чего начать

Откройте **«Рабочий стол Woodright»** (`/app/woodright`):

- **Очередь** — черновики товаров, товары без главного фото (по выборке, не полный подсчёт), быстрый вход в акции.
- **Быстрые действия** — найти товар, создать товар, создать простую акцию.
- **Найти товар и довести карточку** — поиск по названию или артикулу; результат открывает доработку карточки. Запрос хранится в адресе (`?q=`).
- **Недавние** — последние товары (в доработку) и акции (карточка акции).
- **Для поддержки** (свёрнуто) — время обновления данных и служебные ошибки API.

## Как изменить товар

1. Найдите товар через поиск на рабочем столе (или откройте карточку товара — внизу есть блок **«Довести карточку»** → **«Цены и галерея»**).
2. На вкладке **«Обзор»** сверху два блока: **«Заполненность карточки»** (поля товара) и **«На витрине»** (попадает ли в каталог: статус, коллекция, kids). В шапке — кратко «Контент» и «Витрина». «Карточка заполнена» ≠ «товар в каталоге».
3. Измените **Название**, **Описание** или **Статус публикации**. Кнопка **«Сохранить»** пишет только эти три поля; цены и галерея сохраняются во вкладках.
4. Статус «Опубликован» нужен для списков каталога; прямая ссылка `/product/:id` на стенде может открываться и у черновика.
5. Кнопка **«К полной карточке товара»** — наличие, SEO и тип товара.

Вкладки доработки: **Обзор**, **Варианты и цены**, **Галерея**, **Акции товара**, **Служебное**.

Вкладку можно передавать ссылкой (`?tab=variants` и т.п.).

## Варианты и цены

Вкладка **«Варианты и цены»**:

1. Артикул: нажмите **«Изменить»** в строке варианта, введите SKU, сохраните.
2. Цена: редактируется в строке варианта; вводите целое число в рублях, без копеек.
3. **«Массовое изменение простых цен»** — для выбранных строк: **«Установить сумму»**, **«Изменить на сумму»** или **«Изменить на %»**. После записи система перечитывает данные и показывает отчёт.
4. Цены с правилами, прайс-листами или лимитами количества здесь заблокированы — откройте варианты на полной карточке, чтобы не затереть правила.

## Галерея

Вкладка **«Галерея»**:

1. **Главное фото** — то, что видит покупатель в каталоге. Назначается кнопкой в карточке кадра.
2. Порядок кадров меняется стрелками; затем сохраните порядок.
3. Добавление: загрузите файлы (JPG или PNG) — после загрузки они привязываются к товару автоматически.
4. Убрать кадр: действие «Убрать изображение из галереи» с подтверждением. Последний кадр отсюда убрать нельзя — только через полную карточку.
5. Фильтры «Главное / Недоступные / Точные дубли / Проблемы» помогают чистить большие галереи.

## Акции

Полный список акций — раздел **«Акции»** слева (или кнопка **«Все акции»** / **«Открыть все акции»**).

Мастер простой скидки: `/app/woodright/promotions/new` (с рабочего стола, из виджета над списком акций или с хаба `/app/woodright/promotions`).

1. Только **процент** или **фиксированная сумма в рублях**. Без шага кампании: акция без расписания, включение/выключение вручную.
2. Мастер: Скидка → Код или автомат → На что действует → Исключения → Проверка и создание. Финальная кнопка — только **«Создать черновик»** (сразу включить нельзя).
3. На карточке акции: **«Проверить расчёт»** — тестовая корзина через Store API (товар/вариант поиском; ключ из конфигурации стенда). Успех = расчёт системы, **не** доставка скидки на витрину: на сайте нет поля промокода, автоприменение корзины отключено (#14149).
4. **«Включить»** активирует правило в Medusa, но не добавляет промокод на витрину.
5. Акция не переписывает базовые цены товаров.
6. Сложные акции (buy-get, бесплатная доставка, кампании) — в общем разделе акций / полной карточке.

## Вкладка «Акции товара»

Показывает акции, где этот товар или его коллекция выбраны явно. Общие акции магазина здесь не перечисляются.

## Что делать при ошибке

1. Прочитайте заголовок и предложенное действие — все ошибки описаны по-русски.
2. «Для поддержки» / технические сведения раскрывайте только чтобы передать поддержке.
3. Если система пишет о несохранённых изменениях при уходе со страницы — сначала сохраните или осознанно откажитесь.
4. «Данные уже изменились» — обновите страницу и повторите правку.

## Что осталось только на полной карточке / в общих разделах

- Наличие / inventory
- SEO
- Создание и сложное редактирование вариантов
- Сложные цены (правила, прайс-листы)
- Кампании как отдельная сущность
- Room Sets и прочие сущности вне текущего scope Woodright v1

## Изолированная проверка (QA)

Отдельная БД и порт Admin (`:9001`), флаг `WOODRIGHT_ADMIN_UX_V1`. Не путать с общим стендом `:9000`.

Старт: `./scripts/start-woodright-admin-ux-b5.sh start`

Консолидированный smoke четырёх операторских сценариев (Loop 4):

```sh
cd apps/backend
NODE_PATH=/tmp/b5-playwright-qa/node_modules node src/admin/__tests__/woodright-loop4-operator-journeys.smoke.mjs
```

Для проверки акции в корзине на стенде задайте `WOODRIGHT_STORE_PUBLISHABLE_KEY` (или `MEDUSA_PUBLISHABLE_KEY`) в env Admin и перезапустите — ключ в UI вводить не нужно.
