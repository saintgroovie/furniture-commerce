# Руководство оператора — Woodright Admin (черновик Package A)

Это краткое руководство без терминов разработчика. Полные экраны Product Workspace появятся в следующих пакетах (включаются флагом `WOODRIGHT_ADMIN_UX_V1`).

Пока используйте штатную Medusa Admin: `http://localhost:9000/app`.

---

## Как изменить товар

1. Откройте **Products**.  
2. Найдите товар по названию.  
3. Измените название или описание.  
4. Нажмите сохранение на странице товара.  
5. Убедитесь, что статус «Опубликован», если товар должен быть на витрине.

## Как работать с вариантами и ценой

1. В карточке товара откройте варианты.  
2. Проверьте артикул (SKU).  
3. Цену смотрите в блоке цен варианта (в рублях). Если цена «пустая» на экране — не считайте, что её нет: откройте цены варианта явно или дождитесь нового экрана «Варианты и цены».  
4. Не удаляйте единственный вариант без понимания последствий для витрины.

## Как работать с галереей

1. **Главное фото** витрины — это thumbnail товара, не «любой кадр из списка».  
2. Остальные кадры — галерея товара.  
3. Сейчас у части товаров очень много изображений: не удаляйте пачкой без проверки витрины.  
4. Связь «фото ↔ цвет/исполнение» в бизнесе часто живёт в служебных данных — новый экран галереи объяснит это отдельно; не создавайте вторую галерею вне Medusa.

## Как создать акцию

1. Раздел **Promotions** в штатной админке.  
2. Помните: акция **не должна** переписывать базовую цену товара.  
3. До проверки в корзине на витрине не обещайте скидку клиенту.  
4. На текущей витрине авто-применение акций в корзине может быть отключено техническим ограничением — уточняйте у команды перед массовыми акциями.

## Что делать при ошибке

1. Прочитайте заголовок сообщения.  
2. Выполните предложенное действие.  
3. Если есть блок «Технические сведения» — откройте его только для передачи в поддержку.  
4. Не игнорируйте ошибку и не обновляйте страницу до сохранения, если система предупреждает о несохранённых изменениях (появится в Product Workspace).

## Как понять, что сохранилось

- Успешное сообщение «Товар сохранён» / аналог.  
- После обновления страницы данные на месте.  
- Preview витрины показывает те же название/фото/цену.
