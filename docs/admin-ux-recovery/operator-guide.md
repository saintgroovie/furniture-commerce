# Руководство оператора - Woodright Admin (Package F)

Справочник по операторским экранам Woodright. Названия кнопок и вкладок в тексте совпадают с интерфейсом.

Woodright включается флагом `WOODRIGHT_ADMIN_UX_V1` (env и/или localStorage). Если флаг выключен, прямые ссылки на Woodright **сразу открывают** соответствующий экран стандартной админки Medusa (без страницы-заглушки). В левом меню остаётся один пункт Woodright: **«Рабочий стол Woodright»**.

---

## С чего начать

Откройте **«Рабочий стол Woodright»** (пункт в левом меню, адрес `/app/woodright`). На нём:

- **Требуют внимания** - товары в черновике (точный счётчик), товары без главного фото (если каталог большой - это «оценка по выборке», не полный подсчёт) и ссылка на фильтр акций «Требуют внимания». Общего счётчика проблемных акций нет - система его не отдаёт, поэтому мы его не рисуем.
- **Быстрые действия** - кнопки:
  - **«Найти товар»** - переводит курсор в строку поиска ниже
  - **«Товары (стандартная админка)»** - штатный список товаров
  - **«Создать товар»** - штатная форма создания
  - **«Создать акцию»** - мастер акций Woodright
  - **«Акции»** - список акций Woodright (не отдельный пункт меню; открывается с рабочего стола)
  - **«Кампании»** - штатный раздел кампаний
- **Поиск товара** - ищет по названию, handle и артикулу; результат открывает карточку товара Woodright. Ссылку на поиск можно сохранить - запрос хранится в адресе (`?q=`).
- **Недавние изменения** - последние товары и акции по дате обновления.
- **Система** - состояние флага, время последнего обновления данных и свёрнутые «Технические сведения» (нужны только поддержке).

## Как изменить товар

1. Найдите товар через поиск на рабочем столе (или откройте штатную карточку - в ней есть кнопка **«Цены, галерея и акции»**).
2. На вкладке **«Обзор»** измените **Название**, **Описание** или **Статус публикации** (Черновик / Опубликован).
3. Нажмите **«Сохранить»**. Строка состояния под названием подскажет: «Есть несохранённые изменения» → «Сохраняем…» → «Изменения сохранены».
4. Если товар должен быть на витрине - статус «Опубликован».
5. Кнопка **«Стандартная админка Medusa»** в шапке ведёт к штатной карточке этого же товара.

Вкладки Workspace: **Обзор**, **Варианты и цены**, **Галерея**, **Акции товара**, **Служебное**. Наличие и SEO редактируются только в стандартной админке (ссылка под вкладками).

Вкладку можно передавать ссылкой: адрес запоминает открытый раздел (`?tab=variants` и т.п.).

## Варианты и цены

Вкладка **«Варианты и цены»**:

1. Артикул: нажмите **«Изменить»** в строке варианта, введите SKU, сохраните.
2. Цена: редактируется в строке варианта; вводите целое число в рублях, без копеек.
3. **«Массовое изменение простых цен»** - для выбранных строк: **«Установить сумму»**, **«Изменить на сумму»** или **«Изменить на %»**. После записи система перечитывает данные и показывает отчёт - прочитайте его, если что-то не применилось.
4. Цены с правилами, прайс-листами или лимитами количества здесь заблокированы - используйте **«Открыть варианты в стандартной админке»**, чтобы не затереть правила.

## Галерея

Вкладка **«Галерея»**:

1. **Главное фото** - то, что видит покупатель в каталоге. Назначается кнопкой в карточке кадра.
2. Порядок кадров меняется стрелками; затем сохраните порядок.
3. Добавление: загрузите файлы (JPG или PNG) - после загрузки они привязываются к товару автоматически, следите за статусом строк загрузки.
4. Убрать кадр: действие «Убрать изображение из галереи» с подтверждением. Последний кадр отсюда убрать нельзя - только через стандартную админку.
5. Фильтры «Главное / Недоступные / Точные дубли / Проблемы» помогают чистить большие галереи.

## Акции

Список акций Woodright: `/app/woodright/promotions` (с рабочего стола, из виджета на штатном списке акций или по прямой ссылке).

1. Статусы человеческие: «Действует», «Запланирована», «Завершена», «Выключена», «Черновик», «Бюджет исчерпан», «Лимит применений исчерпан», «Ошибка настройки».
2. Фильтры над списком: **Все / Действуют / Запланированы / Завершены / Требуют внимания / По кампаниям**. Фильтр хранится в адресе (`?filter=attention`) - ссылку можно передавать. Помните: фильтр считает только загруженную страницу списка.
3. **«Создать акцию»** - мастер из шести шагов: Скидка → Код или автомат → На что действует → Исключения → Кампания и даты → Проверка и создание. Финальная кнопка - **«Создать как черновик»** или **«Создать и включить»**.
4. В карточке акции: **«Включить»** / **«Выключить»** (обратимо), изменение размера скидки, **«Проверить»** - тестовая корзина через Store API (нужен ID варианта и publishable key; работает в изолированной базе).
5. Акция не переписывает базовые цены товаров - скидка применяется в корзине.
6. Сложные акции (buy-get и другие нераспознанные типы) Woodright не редактирует - для них есть кнопка в стандартную админку.

На штатном списке Medusa Promotions виджет предлагает **«Создать акцию»** (мастер) и ссылку на фильтр проблемных акций.

## Вкладка «Акции товара»

Показывает акции, где этот товар или его коллекция выбраны явно. Общие акции магазина (на весь заказ / весь каталог) здесь не перечисляются. Это тот же раздел акций, что и список `/app/woodright/promotions`, только в разрезе одного товара.

## Что делать при ошибке

1. Прочитайте заголовок и предложенное действие - все ошибки описаны по-русски.
2. «Технические сведения» раскрывайте только чтобы передать поддержке.
3. Если система пишет о несохранённых изменениях при уходе со страницы - сначала сохраните или осознанно откажитесь.
4. «Данные уже изменились» / «Товар был изменён в другой вкладке» - обновите страницу и повторите правку: так вы не затрёте чужие изменения.

## Что осталось только в стандартной админке

- Создание товара и вариантов, удаление товаров и вариантов
- Остатки на складе, категории, коллекции, SEO
- Сложные цены (правила, прайс-листы), сложные типы акций, кампании
- Удаление акций

Кнопка для перехода всегда называется **«Стандартная админка Medusa»** (или явно описывает раздел, например «Открыть варианты в стандартной админке»).

## Как понять, что сохранилось

- Зелёное сообщение «Товар сохранён» / «Цена сохранена» / «Акция создана…» и т.п.
- Строка состояния «Изменения сохранены» на карточке товара.
- После обновления страницы данные на месте; preview витрины показывает то же самое.
