# Package D — operator notes

## Как добавить изображения

Откройте товар → **Рабочее пространство** → **Галерея**. Выберите файлы (JPG/PNG/WEBP/GIF до 8 МБ) и нажмите **Загрузить и добавить в галерею**. Сначала файлы уходят на сервер, затем привязываются к товару. Если привязка не удалась — в списке будет ошибка; файл мог остаться в storage без появления в галерее.

## Как назначить главное

У нужного кадра нажмите **Сделать главным**. На карточке появится метка **Главное**. Главное фото может быть URL вне списка галереи — это нормально для витрины.

## Как изменить порядок

Кнопки **↑ / ↓ / В начало / В конец**. Пока порядок не сохранён — есть **Сохранить порядок** / **Отменить порядок**. Уход со страницы спросит подтверждение.

## Как удалить изображение

**Убрать** отвязывает кадр только от этого товара. Файл в storage Package D **не** удаляет. Последнее изображение убрать здесь нельзя — откройте стандартную админку. Если убираете главное — главным станет следующее в списке.

## Дубли

**Точный дубль URL** — одинаковый адрес после отброса хоста, с учётом регистра пути. Похожие имена файлов без одинакового URL — не точный дубль; Package D их не удаляет сам.

## Когда открыть стандартную админку

Сложная очистка галереи, физическое удаление файла, непонятные ошибки storage — ссылка **Открыть галерею в стандартной админке**.
