# Error message catalog — Woodright Admin

Primary message answers: **what happened**, **what it means**, **what to do**.  
Technical details (status, endpoint, code, request id, raw message, timestamp) go in a collapsible block.

---

## Groups

| Code | Operator title | Explanation | Action |
|------|----------------|-------------|--------|
| `validation` | Не удалось сохранить | Некоторые поля заполнены неверно. | Исправьте отмеченные поля и сохраните снова. |
| `required` | Не хватает обязательных данных | Без этих полей сохранить нельзя. | Заполните поля и повторите. |
| `duplicate_sku` | Такой артикул уже есть | Артикул должен быть уникальным. | Измените SKU и сохраните. |
| `duplicate_option_combo` | Такой вариант уже существует | Комбинация опций повторяется. | Измените опции или откройте существующий вариант. |
| `missing_price` | Нет цены | У варианта нет цены в нужной валюте. | Добавьте цену в рублях и сохраните. |
| `invalid_price` | Некорректная цена | Сумма не подходит для сохранения. | Введите целое число ≥ 0 без скрытых копеек и повторите. |
| `negative_amount` | Отрицательная сумма | Цена не может быть меньше нуля. | Введите 0 или положительную сумму. |
| `missing_price_set` | Нет набора цен | У варианта нет связанного price set. | Откройте варианты в стандартной админке и проверьте цены. |
| `price_not_found` | Цена не найдена | Выбранная цена больше не существует. | Обновите страницу и выберите актуальную цену. |
| `rule_based_price_unsupported` | Сложная цена | У цены есть правила, прайс-лист или лимиты количества. | Измените её в стандартной админке, чтобы не затереть правила. |
| `partial_bulk_failure` | Часть изменений не применилась | Массовая операция завершилась с ошибками по отдельным вариантам. | Посмотрите отчёт и повторите только неудавшиеся строки. |
| `invalid_currency` | Неверная валюта | Указана валюта, которую магазин не использует. | Выберите RUB (или валюту региона) и повторите. |
| `missing_inventory` | Нет связи со складом | Нельзя учесть остаток без складской записи. | Назначьте склад / inventory и повторите. |
| `forbidden` | Недостаточно прав | У вашей учётки нет доступа к действию. | Обратитесь к администратору. |
| `expired_session` | Сессия истекла | Нужно войти снова. | Обновите страницу и войдите. |
| `upload_error` | Не удалось загрузить файл | Файл не сохранён. | Проверьте файл и повторите загрузку. |
| `unsupported_file` | Формат файла не подходит | Этот тип файла не принимается. | Загрузите JPG или PNG. |
| `oversized_file` | Файл слишком большой | Превышен допустимый размер. | Уменьшите файл и повторите. |
| `network_error` | Нет связи с сервером | Запрос не дошёл. | Проверьте сеть и повторите. |
| `timeout` | Сервер долго не отвечает | Запрос прерван по времени. | Повторите попытку. |
| `conflict` | Данные уже изменились | Пока вы редактировали, запись обновилась. | Обновите страницу и внесите изменения снова. |
| `stale_data` | Устаревшие данные на экране | Сохранение отклонено, чтобы не затереть чужие правки. | Обновите и повторите. |
| `deleted_entity` | Запись удалена | Объект больше не существует. | Вернитесь к списку. |
| `promotion_rule_error` | Не удалось настроить условие акции | Условие не принято системой. | Упростите условие или выберите другие товары. |
| `invalid_date_range` | Неверный период | Дата окончания раньше даты начала. | Исправьте даты. |
| `campaign_constraint` | Ограничение кампании | Акция не совместима с правилами кампании. | Измените лимиты или кампанию. |
| `duplicate_promo_code` | Такой код акции уже есть | Код должен быть уникальным среди всех акций. | Придумайте другой код и сохраните. |
| `invalid_promotion_type` | Такой вид акции не поддерживается | Сочетание типа скидки и области действия не принято системой. | Настройте эту акцию в стандартной админке. |
| `invalid_promotion_value` | Некорректный размер скидки | Процент должен быть от 0 до 100, сумма - больше нуля. | Исправьте значение и сохраните. |
| `promotion_unsupported` | Акция сложного типа | Woodright не управляет этим видом акций, чтобы ничего не сломать. | Откройте акцию в стандартной админке. |
| `campaign_budget_conflict` | Конфликт с бюджетом кампании | Валюта или тип бюджета кампании не подходит этой акции. | Выберите другую кампанию или измените бюджет в стандартной админке. |
| `publishable_key_missing` | Нет ключа магазина для проверки | Проверка в корзине требует publishable API key витрины. | Укажите ключ в поле проверки и повторите. |
| `cart_verification_failed` | Проверка в корзине не прошла | Не удалось собрать тестовую корзину или применить код. | Проверьте товар и код, затем повторите. Результат не подтверждён. |
| `promo_code_not_applied` | Код не дал скидку | Корзина собрана, но скидка по коду не появилась. | Проверьте статус акции, её условия и состав тестовой корзины. |
| `unknown` | Что-то пошло не так | Мы не смогли выполнить действие. | Повторите попытку. Если не поможет — откройте технические сведения и передайте их поддержке. |

Package F does not add new codes: the dashboard reuses `network_error` / `timeout` /
HTTP mappings and shows raw HTTP failures only inside the collapsed «Технические сведения»
block of the «Система» card.
