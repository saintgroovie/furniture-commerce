# Чеклист: русский UX/UI копирайт (Woodright)

Использовать перед сдачей правок копирайта / разметки текста.

## Смысл и тон

- [ ] Текст помогает сделать шаг, а не «украшает»
- [ ] Спокойный тон Woodright, без пафоса и канцелярита
- [ ] Активный залог; сначала суть
- [ ] Один экран - один главный смысл
- [ ] Термины совпадают с nav/CTA по всему сайту

## Синтаксис экрана

- [ ] Заголовок + кнопка понятны без тела текста
- [ ] Кнопка действия = инфинитив; «ознакомление» = наречие
- [ ] Нет синонимов для одного действия
- [ ] Заголовки похожих ошибок различаются первыми словами

## Пунктуация Woodright

- [ ] Нет конечной точки у одиночной UI-фразы
- [ ] Точка только между двумя предложениями на одной строке
- [ ] Две мысли лучше отбить строками/`CopyLines` или `lead`+`supporting`
- [ ] Нет `—` / `–`; только ` - `
- [ ] `…` только у процесса (загрузка/отправка)
- [ ] Нет `;` в UI-списках
- [ ] Нет `!` в ошибках
- [ ] UI-списки: заглавная буква, без конечной точки, маркер не `—`/`–` (disc/dot в CSS)

## Переносы

- [ ] Перенос по смыслу
- [ ] Нет висячих коротких предлогов (или включён `CopyLines`/`formatRuInline`)
- [ ] Нет «хвостов» вроде одинокого `под проект` / `по проекту` / строки с ведущим `и …` на следующей строке
- [ ] Collocation (`мебель под проект`, `для взрослых и детских комнат`, `под ключ`…) не разрезана `string[]` и не рвётся wrap
- [ ] Узкие колонки (footer ~38ch): проверить смысловую отбивку, не надеяться только на CSS wrap

## Форматы

- [ ] Empty: title + next step + CTA
- [ ] Error: что случилось + что сделать
- [ ] Success: без гиканья, ясен следующий шаг
- [ ] Form labels/placeholders не дублируются бессмысленно

## Репо

- [ ] Строки в `woodright-copy.ts` (не размазаны по JSX без нужды)
- [ ] Многострочность через `string[]` + `CopyLines`
- [ ] `setError`/alerts через `flatCopy` при необходимости
- [ ] Scope не тащит unrelated dirty tree
